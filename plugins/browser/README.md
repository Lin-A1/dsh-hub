# browser

Browser automation and page-control plugins. These drive a real browser
(headless or headed) to open pages, read snapshots, interact with elements,
and capture screenshots — complementing the stateless `web/` search/fetch
providers.

| Plugin | Capability |
|---|---|
| [`dsh-agent-browser`](dsh-agent-browser/README.md) | Wraps the Vercel `agent-browser` CLI: open/navigate, snapshot, click, fill/type, press, screenshot, eval, get, wait, close; persistent browser session kept alive by the agent-browser daemon |
