# skill

Skill provider registries and the catalog/loader tools that expose them.

| Plugin | Capability |
|---|---|
| [`dsh-anchored-standard`](https://github.com/xiaobright/dsh-anchored-standard) | Experimental agent presets: a base mode, two live-anchor variants, and a seeded prefab mode. They anchor a session on the Minimal condition (real Minimal tool schema, no auto-injected context) and promote to a small resident catalog once the session is durable, unlocking heavier Standard tools on demand. Hub-side entry: [docs/plugins/dsh-anchored-standard/README.md](../../docs/plugins/dsh-anchored-standard/README.md) |
