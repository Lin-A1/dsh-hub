# web

Search/fetch providers and the model-facing web tools built on them.

| Plugin | Capability |
|---|---|
| [`treg`](https://github.com/superdesigndev/treg) | An OpenRouter for tools: one base URL and one token reach ~2,800 catalogued endpoints across ~56 providers (SEO, backlinks, social, enrichment, ads, scraping), priced per call, with a team's own keys/skills/CLIs callable without the credential leaving the server. Hub-side entry: [docs/plugins/treg/README.md](../../docs/plugins/treg/README.md) |

Upstream tracker: [superdesigndev/treg](https://github.com/superdesigndev/treg). Third-party; curated here, maintained upstream.
