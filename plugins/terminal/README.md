# terminal

Persistent PTY/session plugins and their model-facing tools.

| Plugin | Capability |
|---|---|
| [`dsh-ssh-terminal`](https://github.com/Lin-A1/dsh-ssh-terminal) | Persistent SSH remote terminal: long-lived ssh2 shell channels; host chosen per call, gated by an optional allowlist; tools `ssh_terminal_open`/`send`/`read`/`list`/`close` |
