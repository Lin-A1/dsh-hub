# terminal

Persistent PTY/session plugins and their model-facing tools.

| Plugin | Capability |
|---|---|
| [`dsh-ssh-terminal`](dsh-ssh-terminal/README.md) | Persistent SSH remote terminal: long-lived ssh2 shell channels; host chosen per call, gated by an optional allowlist; tools `ssh_terminal_open`/`send`/`read`/`list`/`close` |
