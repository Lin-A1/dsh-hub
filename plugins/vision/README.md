# vision

Vision bridges that let a text-only model read an image as structured evidence.

| Plugin | Capability |
|---|---|
| [`modlens`](https://github.com/liustack/modlens) | Paste an image, get structured evidence — transcription, layout regions, entities, relations — that the model can quote, instead of a prose caption it has to trust. Hub-side entry: [docs/plugins/modlens/README.md](../../docs/plugins/modlens/README.md) |

Upstream tracker: [liustack/modlens](https://github.com/liustack/modlens). Third-party; curated here, maintained upstream.
