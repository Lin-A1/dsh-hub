# sandbox

Process-confinement backends and the approval/permission policy in front of them.

| Plugin | Capability |
|---|---|
| [`mirage`](https://github.com/strukto-ai/mirage) | A unified virtual filesystem for agents: mounts S3, Google Drive, Slack, Gmail, Redis, GitHub, Notion and ~50 other backends as one filesystem, so any agent that knows bash can read/grep/pipe across them with no new vocabulary. Hub-side entry: [docs/plugins/mirage/README.md](../../docs/plugins/mirage/README.md) |

Upstream tracker: [strukto-ai/mirage](https://github.com/strukto-ai/mirage). Third-party; curated here, maintained upstream.
